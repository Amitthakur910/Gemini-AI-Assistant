# Gemini AI Assistant 🤖

A Python-based AI Assistant using Gemini API with CLI and GUI (Tkinter). Supports Q&A, summarization, creative writing, and advice with rate-limit handling and logging.

## Features
- CLI + GUI (Tkinter)
- Uses Gemini API
- Q&A, Summarization, Creative Writing, Advice
- Error handling (429, 503)
- Feedback logging

## Tech Stack
- Python
- Tkinter
- Gemini API

## How to Run
```bash
pip install -r requirements.txt
python app.py
